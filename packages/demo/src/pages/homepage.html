RuntimeKit is an experimental interception-based web proxy, designed to evade internet censorship and bypass arbitrary browser restrictions.

RuntimeKit allows you to sandbox arbitrary web content, bypass CORS restrictions on loading websites, and instrument and debug websites inside the browser itself. This is accomplished through a combination of interception, rewriting, and sandboxing techniques. You can learn more about the technical details here.

If you're interested in contributing to runtimekit, or want to build your own web proxy or application using it, you should check out the GitHub repository.

This website is a demo of runtimekit's capabilities, letting you browse the web proxied through runtimekit, inspect how runtimekit rewrites requests and responses, and see how runtimekit handles your custom content in the playground.

Browser

Try entering a URL in the box above to browse the web proxied through runtimekit.
All traffic sent through runtimekit is fully end-to-end encrypted with TLS, powered by httpengine.js and the streamRelay protocol.

Requests

You can inspect all the requests sent through runtimekit, and what transformations are applied in the requests tab.
Note that requests will not be captured until you first click on the requests tab.

Playground

The playground lets you write your own html/css/js snippets which will be run inside the runtimekit sandbox. Your files are "served" by runtimekit from a fake origin, which can be configured to be any URL. Notice that if you add a console.log(location.href) in your code, the page will really be running on the fake origin.
